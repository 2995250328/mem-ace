\section{Introduction}

Camera relocalization estimates the six-degree-of-freedom pose of a query image in a known scene. Scene coordinate regression (SCR) solves this problem by predicting dense 3D scene coordinates and recovering pose from the resulting 2D--3D correspondences. ACE-style methods make SCR efficient by separating image encoding from a lightweight scene-specific coordinate regressor. However, scene evidence is still commonly absorbed into the parameters of that regressor, which makes the representation difficult to inspect, cache, or reuse across compatible SCR systems.

We address this problem with \method{}, a compact scene-memory interface for SCR. \method{} builds a pooled memory bank from posed mapping images and reconstruction geometry, where visual features are associated with 3D scene points. A global Geo-token Compressor aggregates this point-feature memory into a small fixed set of anchored scene tokens. Each token retains learned content and a sampled 3D anchor, so the compressed representation preserves spatial organization without requiring every query image to read the full memory bank.

For a query image, a single Memory Fusion block conditions dense image features on both token content and anchor geometry encoded relative to the scene center. A standard coordinate head then predicts dense scene coordinates in the same reference frame. The same center also anchors the coordinate-head parameterization, coupling the geometry exposed by the memory with the coordinate representation learned by SCR. During training, \method{} first aligns the compressor, fusion module, and coordinate head, then caches the compressed scene tokens while adapting the downstream predictor. Verified SfM tracks provide additional cross-view reprojection constraints when available.

The proposed representation is independent of a particular feature source or SCR head. We use backbone-specific visual features to construct memory and evaluate the same token interface in ACE-style and GLACE-compatible coordinate-regression pipelines. This separation lets the paper study scene-memory compression and fusion directly, rather than presenting a new backbone or pose solver.

This paper makes three contributions. First, we introduce \method{}, a compact anchored scene-memory representation that globally aggregates point-feature memory into a fixed number of reusable tokens. Second, we design scene-centered Memory Fusion and a cached adaptation procedure that preserve the standard SCR coordinate-regression pipeline. Third, we evaluate the representation across indoor and outdoor relocalization settings, including compatibility with existing SCR architectures.
