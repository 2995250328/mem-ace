\section{Conclusion}

We introduced \method{}, a plug-in approach for compressing scene memory into latent tokens and using those tokens to condition visual relocalization backbones. The framework supports both DINOv2 with MapAnything memory and ACE-FCN memory connected to GLACE-style global-local regression. Current results on Indoor6 and Wayspots show that compact scene memory can improve compatible relocalization settings, while negative-transfer cases highlight the need for visibility-guided local/global configuration selection. The remaining experiments will determine the strength of the final AAAI claim, especially for full Wayspots aggregation, clean Indoor6 ACE-FCN+GLACE summaries, Cambridge, APR+LMC, and ACE-G+LMC.
