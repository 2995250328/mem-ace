\section{Conclusion}

We introduced \method{}, a compact scene-memory interface for scene coordinate regression. \method{} globally compresses pooled point-feature memory into anchored scene tokens, conditions query features on token content and scene-centered geometry, and retains a standard coordinate-regression head. The resulting representation can be cached per scene and integrated with compatible SCR architectures. The final evaluation will consolidate Indoor6, Wayspots, and Cambridge results, quantify capacity and efficiency, and test whether the representation improves cross-view consistency under the fixed global protocol.
