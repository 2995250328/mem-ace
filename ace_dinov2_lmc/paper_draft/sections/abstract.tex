\begin{abstract}
Visual relocalization benefits from scene-specific representations, yet existing systems often bind scene memory to a particular coordinate-regression architecture or inject global scene cues without accounting for their scene-dependent reliability. We present \method{} (\shortmethod{}), a plug-in scene-memory representation module for visual relocalization. \shortmethod{} compresses map-derived or backbone-aligned memory into compact latent tokens and conditions coordinate-regression backbones through local or global fusion. The framework supports a one-level two-stage setting, where DINOv2 features are conditioned by MapAnything-derived memory on Indoor6, and a two-level two-stage setting, where ACE-FCN memory is first learned as a local scene representation and then connected to a GLACE-style global-local regressor. To reduce unreliable global conditioning, we formalize a visibility-guided configuration selection rule that falls back to local or hierarchical conditioning when memory visibility is insufficient. Experiments on Indoor6 and Wayspots provide evidence that compact latent scene memory can improve compatible relocalization pipelines, while SquareBench exposes negative transfer from unguarded global features. These findings position latent scene memory as a practical representation interface for robust relocalization rather than a universal replacement for existing backbones.
\end{abstract}
