\section{Experiments}

\subsection{Protocol}

We evaluate camera relocalization using median rotation error in degrees, median translation error in centimeters, and threshold accuracies. \acctwentyfive{}, \accten{}, and \accfive{} denote the percentages of test frames below the corresponding pose-error thresholds. Unless otherwise specified, the paper-safe Indoor6 source uses post-training multi-seed median evaluation and selects checkpoints by \accfive{}. Exact hypotheses, thresholds, split definitions, and seed lists must be reported in the final camera-ready version.

\subsection{Ablations and Missing Experiments}

For Wayspots, the remaining method-side experiments are memory controls with zero/random/shuffled memory, a token-capacity sweep under the fixed global-compression protocol, and a final single-configuration Stage2 run so that the paper table does not mix different fusion choices. For Indoor6, the remaining experiments are finishing the selected DINOv2+MapAnything-memory configuration on all scenes, sweeping latent-token count $K$ on the main setting, and testing the image-level relative-depth consistency loss as an auxiliary objective rather than a buffer-only supervision signal.

Across both datasets, the final paper needs a compact efficiency table reporting token count, memory size, training time, evaluation latency, and peak GPU memory. Cambridge, APR+LMC, and ACE-G+LMC should remain explicit extensions until their baseline contracts and evaluation scripts are stable.
