\section{Method}

\subsection{Overview and Scene Memory}

Let $I$ denote a query image and $Q=B(I)$ the dense feature map produced by an SCR backbone. Standard SCR predicts a scene coordinate $\hat{X}(u)$ at each image location $u$ and recovers camera pose from the resulting 2D--3D correspondences. \method{} augments this pipeline with a scene memory
\begin{equation}
    \mathcal{M}=\{(p_i,f_i)\}_{i=1}^{N},
\end{equation}
where $p_i\in\mathbb{R}^{3}$ is a scene point and $f_i\in\mathbb{R}^{D}$ is its aligned visual feature. We construct $\mathcal{M}$ offline from posed mapping images and an SfM reconstruction by associating feature samples with patch-level 3D support and pooling the resulting point-feature pairs. The memory additionally stores a scene center $c$ in the coordinate contract used by the coordinate head.

\subsection{Global Geo-token Compression}

The Geo-token Compressor maps the full pooled scene memory to a compact set of anchored scene tokens:
\begin{equation}
    \mathcal{C}_{\theta}(\mathcal{M},c)
    \longrightarrow
    \mathcal{T}=\{(z_k,p_k)\}_{k=1}^{K},
    \qquad z_k\in\mathbb{R}^{d},\; p_k\in\mathbb{R}^{3}.
\end{equation}
In all paper-facing runs, we use global compression: every anchor aggregates information from the pooled scene memory through geometry-aware attention. We select the $K$ anchors $p_k$ from memory points with farthest-point sampling, using the scene center to initialize the sampling. Their scene-centered positions $p_k-c$ initialize geometric queries, which attend to the point-feature memory and produce the content tokens $z_k$. Unless otherwise specified, $K=64$.

The anchors are part of the compressed scene representation, not coordinate predictions. They are neither decoded by the SCR head nor given an independent coordinate loss. The coordinate head remains responsible for predicting $\hat{X}(u)$ from query-conditioned features.

\subsection{Scene-Centered Memory Fusion}

For each token, \method{} combines content with scene-centered anchor geometry before a single cross-attention read. Let $\phi(\cdot)$ be a Fourier position encoder and $P_{\mathrm{geo}}$ its learned projection. The default `value\_only\_raw' fusion constructs attention keys and values as
\begin{equation}
    g_k=P_{\mathrm{geo}}\bigl(\phi(p_k-c)\bigr),
    \qquad
    k_k=W_K z_k,
    \qquad
    v_k=W_V(z_k+g_k).
\end{equation}
Thus, anchor geometry enriches attention values while keys retain content-based matching. Query features read the $K$ tokens once, followed by residual and feed-forward refinement:
\begin{equation}
    \tilde q_u=F_{\varphi}(q_u,\mathcal{T},c),
    \qquad
    \hat{X}(u)=H_{\psi}(\tilde q_u).
\end{equation}
The coordinate-head mean is aligned with the same scene center $c$, so the geometry supplied by memory and the output coordinate parameterization share a common reference.

\subsection{Geometric Alignment and Cached Memory Adaptation}

Each training iteration has two semantic steps. In \emph{Geometric Alignment}, we jointly update $\mathcal{C}_{\theta}$, $F_{\varphi}$, and $H_{\psi}$ so that the compressed tokens support coordinate regression. In \emph{Cached Memory Adaptation}, we compute $(Z,P)=\mathcal{C}_{\theta}(\mathcal{M},c)$ once, freeze the compressor, and cache these tokens while adapting the fusion module and coordinate head. This separation stabilizes the scene representation during downstream refinement and allows the same tokens to be reused across query images.

For a source observation $u_s$, source-frame reprojection gives
\begin{equation}
    \mathcal{L}_{\mathrm{src}}
    =\rho\bigl(\pi_s(\hat{X}(u_s))-u_s\bigr),
\end{equation}
where $\pi_s$ uses the known source camera and $\rho$ is the reprojection loss. When verified SfM tracks provide a target observation $u_t$ of the same point, Cached Memory Adaptation additionally uses
\begin{equation}
    \mathcal{L}_{\mathrm{track}}
    =\rho\bigl(\pi_t(\hat{X}(u_s))-u_t\bigr),
    \qquad
    \mathcal{L}=\mathcal{L}_{\mathrm{src}}+
    \lambda_{\mathrm{track}}\mathcal{L}_{\mathrm{track}}.
\end{equation}
This cross-view term constrains a coordinate predicted from one observation to reproject to its matched observation in another view.
