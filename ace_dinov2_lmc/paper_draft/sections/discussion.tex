\section{Discussion}

The current evidence supports a cautious interpretation of \shortmethod{}. Compact latent scene memory can improve relocalization when the memory source and fusion path are compatible with the backbone. The Indoor6 DINOv2+MapAnything results support the one-level two-stage setting, and the ACE-FCN memory plus GLACE experiments suggest that local latent memory can also serve as a bridge into a different global-local architecture. However, the Wayspots SquareBench behavior shows that global features can cause negative transfer. This finding should be treated as a central reliability motivation rather than as an outlier to remove from the paper.

The practical implication is that \shortmethod{} should be presented as a plug-in representation interface with configuration selection, not as a universal global-context module. Local memory is often safer, global conditioning can be stronger when reliable, and \gvcs{} provides a deterministic first step toward selecting between these modes. More sophisticated learned reliability models may be useful in future work, but the current paper should only claim the visibility-guided rule implemented and evaluated in the codebase.

Several limitations remain. The Indoor6 ACE-FCN+GLACE evidence requires a clean all-scene summary before final submission. Wayspots full-scene aggregation is needed to avoid overemphasizing Bears. Cambridge and APR+LMC experiments are important for testing outdoor scalability and non-SCR generality, respectively. Finally, the relationship between \shortmethod{} and ACE-G map-code representations should be evaluated directly or clearly described as future work.
