# Method Architecture Figure Prep

This folder contains paper-facing preparation materials for the GLACE + GeoLMC Memory method figure.

This is not an evaluation artifact. It lives under `paper_experiment_matrix/03_figures/` because it is part of paper writing, figure design, and method communication.

Files:

- `open_source_workflow.md`: open-source figure/prompt workflow distilled for this project.
- `figure_spec.md`: source-of-truth architecture description.
- `method_architecture.mmd`: Mermaid structural draft for checking modules and arrows.
- `image2_prompt.md`: copy-paste prompts for image2.

Recommended workflow:

1. Read `open_source_workflow.md` to keep the figure-generation process grounded in open-source practices.
2. Check `figure_spec.md` for method correctness.
3. Render or inspect `method_architecture.mmd` as the structural draft.
4. Use `image2_prompt.md` to generate visual references.
5. Recreate the final paper figure in a vector tool if generated text or arrows are imperfect.
