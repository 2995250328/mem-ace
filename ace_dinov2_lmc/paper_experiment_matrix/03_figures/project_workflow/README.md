# Project Workflow Figure Prep

This folder contains a paper-facing workflow diagram for the current GLACE + GeoLMC Memory research work.

It is different from `../method_architecture/`:

- `method_architecture/` describes the model architecture.
- `project_workflow/` describes the research workflow: open-source diagram planning, project-specific method definition, experiments, result consolidation, and paper assets.

Files:

- `workflow_spec.md`: source-of-truth workflow definition.
- `project_workflow.mmd`: editable Mermaid flowchart.
- `project_workflow.svg`: rendered deterministic SVG flowchart.
- `image2_prompt.md`: prompt for generating a polished workflow figure reference.
